# Ngoc Minh Ngan Bui — Researcher Website

A responsive, multi-page static website built with plain HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `research.html` — Research, publications, and scientific events
- `journey.html` — Interactive chronological timeline and world map
- `connect.html` — Contact and research profiles

## Local preview
Open `index.html` directly in a browser, or run a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
Upload all files and the `assets` folder to a GitHub repository, then enable **Settings → Pages → Deploy from a branch**.

## Editing
Shared styling is in `styles.css`; interactions and journey data are in `script.js`.
